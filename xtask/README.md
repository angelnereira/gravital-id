# xtask — Automatización y validación del repositorio

Binario de tareas para Gravital ID (`cargo xtask`).

## Comandos

- `cargo xtask check-layers`: Valida reglas de capas e invariantes arquitectónicas.
- `cargo xtask trace`: Genera y valida matriz de trazabilidad REQ -> pruebas.
- `cargo xtask check-error-codes`: Valida unicidad y documentación de códigos de error.
