# Issues pendientes de sincronizar

Respaldo para cuando un agente **no** puede crear issues en GitHub (`AGENTS.md §7.3`).

1. Crea `YYYYMMDD-<slug>.md` aquí usando la plantilla correspondiente de `.github/ISSUE_TEMPLATE/` (incluido el bloque de metadatos).
2. Inclúyelo en tu PR y menciónalo en la nota de traspaso.
3. Quien tenga acceso crea el issue en GitHub, añade al inicio del archivo `Issue: #<número>` y lo mueve a `.issues/synced/`.

**Nunca** registres aquí vulnerabilidades explotables: sigue `SECURITY.md`.
